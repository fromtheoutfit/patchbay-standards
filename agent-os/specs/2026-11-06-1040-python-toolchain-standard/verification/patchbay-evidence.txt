### 5. uv_build: what the [build-system] range changes under uv 0.13.7
uv documents that it builds with the backend bundled in it "if its version is compatible with
the uv_build requirement" and otherwise uses a compatible uv_build package
(https://docs.astral.sh/uv/concepts/build-backend/). Under uv 0.13.7, offline and with no cache,
both uv build and the editable build of uv sync build with the bundled backend whatever the range
says; a range that does not contain the running uv is a warning, and the build succeeds.

$ requires = ["uv_build>=0.13.7,<0.14.0"]; uv build --wheel --offline --no-cache -v -o <scratch>/wheels

exit=0
