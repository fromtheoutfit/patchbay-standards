Every probe runs on an export of fromtheoutfit/patchbay at 7471387 (origin/main, the merge of PR 11;
`git archive 7471387`, shown as <export>), from its root, through its locked environment: python as
`uv run --locked python <script>`, mypy as `uv run --locked mypy <script>` and ruff as
`uv run --locked ruff check --no-cache <script>`, so each tool reads patchbay's [tool.*] (ruff select ALL
with its six ignores, mypy strict with warn_unreachable and implicit_reexport = false, pytest's addopts)
at the versions uv.lock pins. VIRTUAL_ENV is unset, so uv uses the export's own .venv.

Section 1 reruns patchbay's own probes verbatim and compares each output with the one recorded in
patchbay at 7471387. Section 2 holds the probes this spec adds where no patchbay probe covers a claim a
rule rests on. Each new probe's source is shown before its output, and its cases put the claim beside
the one it competes with: the refusal beside the acceptance, the rule's case beside the case it is not.

What the standards take from them:

- Section 1, every rerun identical to patchbay's recorded output (paths, addresses and timings aside):
  runtime.py 1-7 (models: read-only mapping, base64 bytes, the array, strict, frozen assignment;
  typing: runtime_checkable and issubclass), typing_probe.py A-J (models: the class keyword is what
  mypy reads; typing: NewType keys; events: Subscriber contravariant, its parameter's name free),
  strict_nested.py and config_form.py (models: strict at depth, the keyword and model_config),

  models_init.py (models: the base-init marker), footing.py A-E and footing_typing.py (models: the
  wrapped classmethods, from_json_data, the exact sample count, the constrained key; events: the
  zone judged), and mutations.py (tests: the widest-bounds test fails twice with the old arithmetic).
- a, nested_refusal.py: a ValueError in a nested validator is collected with its path beside the
  outer model's own refusal; a TypeError passes through pydantic-core unwrapped and the outer refusal
  is lost. Without __pydantic_base_init__, PatchbayModel's own refusing __init__ refuses a valid JSON
  enum one level down, and a refusal loses the outer path and the outer field's refusal; with it
  (patchbay's PatchbayModel) both are right. model_copy(update=...) on a patchbay model validates
  nothing: a str lands in a float field (a5) (models).
- b, ruff_rules.py: D401 reports a non-imperative docstring, and not on a function named test_*, so
  the prefix waived it; the contract tests' first-round docstring "The instrument exposes ..." is
  reported once unprefixed. PGH003 reports a blanket `# type: ignore` and not a coded one; BLE001 the
  catch of every Exception; PLR2004 a magic value in a comparison and not one in arithmetic
  (toolchain, tests, events).
- c and k, mypy_rules.py: under strict, an unused coded ignore is an error (unused-ignore), a used one
  passes; under implicit_reexport = false a name a module imports but does not list in __all__ is not
  exported (attr-defined), and --implicit-reexport lifts it (typing, tests).
- d, optimized.py: python -O strips assert; a raised AssertionError subclass survives it (tests).
- e, pytest_probe: pytest collects a test_-named function a test module imports by name, and neither
  an unprefixed one nor a contract test imported from patchbay.testing (tests).
- f and o, tool_facts.py: one float past 2**53 and past the largest float (nextafter; bound + 1.0 is
  the bound); pydantic's ValidationError.errors is a method and pydantic does not re-export
  ErrorDetails, which is pydantic-core's; \d matches U+0661 and [0-9] does not; an error that

    # Usage: extract.py <export>/agent-os/specs <out>
    import re, sys, pathlib
    base = pathlib.Path(sys.argv[1]); out = pathlib.Path(sys.argv[2]); out.mkdir(parents=True, exist_ok=True)

    p1 = (base / "2026-11-07-0806-contracts-models-events-errors-fake/verification/probes.txt").read_text().splitlines()
    # P1: "$ cat probes/X.py" ... "$ uv run --locked <tool> probes/X.py" ... until next "$ " or "=====" line
    i = 0
    while i < len(p1):
        m = re.match(r"^\$ cat probes/(\S+)$", p1[i])
        if not m:
            i += 1; continue
        name = m.group(1); j = i + 1; src = []
        while not p1[j].startswith("$ "):
            src.append(p1[j]); j += 1
        while src and not src[-1].strip(): src.pop()
        (out / name).write_text("\n".join(src) + "\n")
        while j < len(p1) and p1[j].startswith("$ uv run"):
            cmd = p1[j]; tool = cmd.split()[4]; k = j + 1; o = []
            while k < len(p1) and not p1[k].startswith("$ ") and not p1[k].startswith("====="):
                o.append(p1[k]); k += 1
            while o and not o[-1].strip(): o.pop()
            (rec / f"{name}.{tool}.txt").write_text("\n".join(o) + "\n")
            j = k
        i = j
    # P2: "probes/X.py" header, source, "---- output (...)" line, output, "=====".
    p2 = (base / "2026-11-07-1432-contracts-revision-after-pr-11-review/verification/probes.txt").read_text().splitlines()
    for i, line in enumerate(p2):
        m = re.match(r"^probes/(\S+\.py)$", line)
        if not m or not p2[i - 1].startswith("====="):
            continue
        name = m.group(1); j = i + 1; src = []
        while not p2[j].startswith("-" * 20):
            src.append(p2[j]); j += 1
        while src and not src[0].strip(): src.pop(0)
        while src and not src[-1].strip(): src.pop()
        tool = "mypy" if "mypy" in p2[j] else "python"
        (out / name).write_text("\n".join(src) + "\n")
        k = j + 1; o = []
        while k < len(p2) and not p2[k].startswith("====="):
            o.append(p2[k]); k += 1
        while o and not o[0].strip(): o.pop(0)
        while o and not o[-1].strip(): o.pop()
        (rec / f"{name}.{tool}.txt").write_text("\n".join(o) + "\n")
    m3 = (base / "2026-11-07-1432-contracts-revision-after-pr-11-review/verification/mutations.txt").read_text().splitlines()
    s = m3.index("probes/mutations.py"); e = next(k for k in range(s, len(m3)) if m3[k].startswith("-" * 20))
    src = m3[s + 1:e]
    while src and not src[0].strip(): src.pop(0)
    while src and not src[-1].strip(): src.pop()
    (out / "mutations.py").write_text("\n".join(src) + "\n")
    (rec / "mutations.py.python.txt").write_text("\n".join(l for l in m3[e + 1:] if l.strip()) + "\n")

pydantic-core collects a ValueError raised inside a validator as one refusal with its path and
goes on validating; any other exception passes through it unwrapped. Each case puts a refusal in

reported and with what path.

from typing import Any

from pydantic import BaseModel, ConfigDict, ValidationError, field_validator

def case(label: str, fn: Any) -> None:
    try:
        print(f"{label}: ok -> {fn()!r}")
    except ValidationError as error:
        print(f"{label}: pydantic ValidationError at {[e['loc'] for e in error.errors()]}")
    except PatchbayValidationError as error:
        print(f"{label}: PatchbayValidationError at {[d['loc'] for d in error.details]}")
    except Exception as error:  # noqa: BLE001
        print(f"{label}: {type(error).__name__} passed through: {error}")


class InnerValue(BaseModel):
    x: float

    @field_validator("x")
    @classmethod
    def _positive(cls, x: float) -> float:
        if x < 0:
            raise ValueError("x is negative")
        return x

        return x
